presentation/
  index.html        the whole app: Edit mode + Present mode
  slides.js         slide list, written automatically by Edit mode
  assets/pages/     PDF pages (created by the editor)
  assets/media/     videos, GIFs, images (created by the editor)

EDIT MODE (open index.html in Chrome or Edge)
  1. Click "Connect folder" and pick this folder.
  2. Drop PDFs / videos / GIFs onto the window. PDFs become one slide per page.
  3. Drag cards to reorder. Pick a transition per slide in the side panel.
  4. Changes save automatically into slides.js.

PRESENT MODE
  Click "Present" (or double-click a card). Click, arrow keys, space or swipe to advance.
  F = fullscreen, P = play/pause video, Esc = back to editor.

PUBLISHING
  Upload this whole folder to GitHub Pages. The public site opens straight
  into Present mode with no editor.
